# FloodSolve 1000

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fperemiller%2Ffloodsolve-1000&project-name=floodsolve-global-atlas)

FloodSolve 1000 is an interactive global flood-risk solutions atlas. It combines 50 intervention strategies with 20 representative flood-prone settings to provide exactly 1,000 searchable implementation briefs.

## Features

- 1,000 tailored flood-risk solutions
- Search, sorting, pagination, grid, and list views
- Filters for flood type, setting, category, approach, cost, and implementation horizon
- Detailed implementation sequences, cautions, delivery coalitions, and success measures
- Responsive, accessible static interface

## Local use

Open `dist/index.html` in a browser, or serve the `dist` directory with any static web server.

## Deployment

The project is configured for Vercel through `vercel.json`. The production output directory is `dist`.

## Important note

This atlas is a decision-starting resource, not a substitute for local hydrology, engineering, environmental review, lifecycle costing, or community consent.
